GET STARTED

Download. Extract. Install.

Use the standalone archive for installation, or follow the repository README to run from source.

  1. 1

    Download the release archive

    Open GitHub Releases and download GreatSage_Raphael-1.0.1-linux-x86_64.tar.gz. The accompanying .sha256 file can verify the download. Choose the application archive, rather than GitHub's “Source code” ZIP.

  2. 2

    Extract and install

    Open a terminal in the directory containing the downloaded archive, then run:

    tar -xzf GreatSage_Raphael-1.0.1-linux-x86_64.tar.gz
cd GreatSage_Raphael-1.0.1-linux-x86_64
./install.sh --desktop

    The installer adds an application-menu entry and desktop shortcut for the current account. No sudo is required.

  3. 3

    Open the application

    Launch GreatSage_Raphael from the application menu or desktop. Alternatively:

    ~/.local/bin/greatsage-raphael

    Select Open capture, choose a PCAP or PCAPNG file, and select a finding to inspect its details. Five sample captures are available in the repository.

Verify the downloaded archive

Place both downloaded files in the same directory and run:

sha256sum -c GreatSage_Raphael-1.0.1-linux-x86_64.tar.gz.sha256
Uninstall the application
~/.local/share/greatsage-raphael/uninstall.sh

Captures and reports outside the installation directory are preserved.

Interpret findings in context

Findings are observations, not proof of malicious intent. No findings does not establish network safety. Supported protocols and analysis limitations are documented in the repository README.
